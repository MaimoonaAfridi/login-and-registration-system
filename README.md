# login-and-registration-system
## Description
This project is a Login and Registration System developed in C++ using file handling.

## Features
- User Registration
- User Login Authentication
- Duplicate Username Checking
- Secure Credential Storage using Files
- Success and Error Messages

## Technologies Used
- C++
- File Handling
- Functions

## How It Works
The program allows users to create an account by registering a username and password. The credentials are stored in files, and users can log in using their registered information.
